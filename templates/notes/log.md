# Session log

Append-only. Newest first. Never edited — an entry is a record of what you thought at a
moment, not current belief. Current belief lives in `problem.md` and `literature.md`.

Written by `/handoff` at the end of a working session, or by hand. Three lines is fine; the
failure mode is skipping it, not writing it badly.

Format:

```
## YYYY-MM-DD — <one-line summary>
**Did:**
**Concluded:**
**Next:**
**Loose ends:**
```

`Loose ends` is for the thing you'd have forgotten by Thursday: a check you skipped, a
number that looked slightly off, an assumption you made to keep moving. It's the highest
value line in the entry and the easiest to leave blank.

---

## <date> — project started

**Did:** Set up repo, notes skeleton, skills.
**Concluded:** —
**Next:** `/scope-the-question`.
**Loose ends:** —
